# 🎨 Random Color Palette Generator

A simple and interactive **Random Color Palette Generator** built with **HTML, CSS, and JavaScript**. Generate beautiful random color palettes instantly with a single click and explore different color combinations for your projects.

---

## 🚀 Features

- 🎲 Generate 5 random colors instantly
- 🎨 Beautiful color palette display
- 🔄 One-click palette regeneration
- 📋 Copy hex color codes to clipboard
- 📱 Responsive design for desktop and mobile
- ⚡ Fast and lightweight with no dependencies

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Font Awesome Icons

---

## ⚙️ How It Works

1. User clicks the **Generate Color** button.
2. JavaScript generates random hexadecimal color codes.
3. The palette updates dynamically.
4. Users can copy any color code for use in their own projects.
